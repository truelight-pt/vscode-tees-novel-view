# サンプル

拡張機能の動作確認用のサンプルです。このフォルダー（または開発フォルダー全体）を VS Code で開くと、物語ファイル一覧の自動検知の動きを確認できます。

| ファイル | 物語ファイル一覧 | 確認できること |
| --- | --- | --- |
| `表示サンプル/表示サンプル.txt` | 表示される（内容から検知） | ルビ、会話文・心の声・『』・数字（漢数字を含む）の色分け、ルビにしない書き方 |
| `小説/第1章/第01話.txt`〜`第03話.txt` | 表示される（内容から検知） | ファイル名の右のタイトル表示、前話・次話への移動 |
| `小説/第2章/第04話.txt`・`第05話.txt` | 表示される | 章ごとのフォルダー分け |
| `小説/あとがき.txt` | 表示される（フォルダー単位で検知） | 内容だけでは物語と判定されないが、物語ファイルと同じフォルダーにあるため表示される |
| `メモ/プロット.txt`・`用語集.txt` | **表示されない** | 物語らしい特徴（ルビ・会話文・字下げ）が無く、物語ファイルのフォルダーの外にある |

この `README.md` は `.txt` 以外のファイルなので、物語用のフォルダーとみなす範囲はここ（`sample/`）で止まります。そのため、`小説/` の物語ファイルが検知されても、`メモ/` までは広がりません。
